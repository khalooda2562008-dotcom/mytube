    الإعدادات والربط

    إزاي أجيب المفاتيح؟ (خطوة بخطوة)
    1. افتح console.cloud.google.com وأنشئ مشروعاً جديداً.
    2. من APIs & Services → Library فعّل YouTube Data API v3.
    3. من Credentials أنشئ API key والصقه في الحقل الأول.
    4. أنشئ OAuth client ID من نوع Web application، وأضف النطاق … في Authorized JavaScript origins، ثم الصق المعرّف في الحقل الثاني.
    5. من aistudio.google.com/apikey أنشئ مفتاح Gemini والصقه في الحقل الثالث.
    6. احفظ ثم اضغط «ربط حساب Google» مرة واحدة للموافقة على قراءة اشتراكاتك.

    كل المفاتيح تُحفظ في متصفح جهازك فقط ولا ترسل لأي سيرفر غير جوجل.
